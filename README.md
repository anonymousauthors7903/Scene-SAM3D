# Scene-SAM3D

Anonymous supplementary project page.

This directory contains only the static website and its referenced assets.
The teaser is 2560 x 1440; eight instance examples and five scene examples
include interactive 3D comparisons.

Publish the contents at the repository root. In Settings > Pages, select
Deploy from a branch, main, / (root). Keep .nojekyll in place.

Test through an HTTP server rather than opening index.html as a local file.
Web fonts and optional model-viewer decoders may access external services.
Bundled third-party notices are retained. No new license is granted here.
